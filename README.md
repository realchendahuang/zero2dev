## 🎯 设立宗旨

有了 AI 编程助手之后，传统的转码路线（背语法、刷 LeetCode、背八股文）已经完全过时。

对文科生、产品经理和非科班建造者而言，写代码的核心不再是手敲语法，而是**工程直觉与交付闭环**：
- **以终为始**：从一个真正能解决自己痛点的小工具开始；
- **AI 螺旋进化**：学会与 Coding Agent 协作，在报错中建立工坊手感；
- **跑通完整生命周期**：从本地环境、Git 管理、前端界面到边缘部署上线。

---

## 🗺️ 认知与实战路径

1. **第一关：工坊手感建立** - 终端、文件系统、Markdown 与 Git 基础心智
2. **第二关：与 AI 对齐需求** - 怎么写精确的需求规格，避免大模型幻觉与代码腐化
3. **第三关：现代轻量技术栈** - Vite, Tailwind CSS, Cloudflare Pages, Hono 极简组合
4. **第四关：独立上线与第一波读者** - 部署自动化、独立域名绑定与冷启动交付
